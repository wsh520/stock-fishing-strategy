## 错误1: _market_environment 导入错误

### 报错信息
```
ImportError: cannot import name '_market_environment' from 'src.bottom_fishing_strategy'
```

### 原因
`src/bottom_fishing_strategy.py` 中不存在 `_market_environment` 函数（下划线开头通常表示私有函数）。

实际存在的函数是：
- `get_market_environment()` - 公共函数（第4623行）
- `compute_market_environment()` - 计算函数（第1829行）

### 修复内容

#### 1. 修复导入语句（第30行）
```python
# 修复前 ❌
from src.bottom_fishing_strategy import (
    get_stock_list, get_index_daily, _market_environment,
    ...
)

# 修复后 ✅
from src.bottom_fishing_strategy import (
    get_stock_list, get_index_daily, get_market_environment,
    ...
)
```

#### 2. 修复函数调用（第66行）
```python
# 修复前 ❌
market_env = _market_environment(config, cache, index_df)

# 修复后 ✅
market_env = get_market_environment(config, cache)
```

**注意**：`get_market_environment` 只需要2个参数（config, cache），不需要 index_df。

## 错误2: save_recommendation 导入错误

### 报错信息
```
ImportError: cannot import name 'save_recommendation' from 'store.mysql_store'
```

### 原因
函数名错误，实际函数名是 `save_recommendations`（复数形式）。

在 `store/mysql_store.py` 第258行：
```python
def save_recommendations(df: Optional[pd.DataFrame], strategy: str = STRATEGY_BOTTOM_FISHING) -> int:
```

### 修复内容

#### 1. 修复导入语句（第34行）
```python
# 修复前 ❌
from store.mysql_store import save_recommendation

# 修复后 ✅
from store.mysql_store import save_recommendations
```

#### 2. 修复函数调用（落库部分）
```python
# 修复前 ❌
saved = save_recommendation(ranked, strategy="longterm_quality")

# 修复后 ✅
saved = save_recommendations(ranked, strategy="longterm_quality")
```

## 根本原因分析

这些错误都是**函数命名不一致**导致的：

1. **私有函数误用**：`_market_environment` 实际是公共函数 `get_market_environment`
2. **单复数混淆**：`save_recommendation` 实际是 `save_recommendations`（复数）
3. **版本过期**：Actions v3 已被 GitHub 弃用

这类问题在项目开发过程中很常见，尤其是在：
- 函数重构后，调用方未同步更新
- 新文件创建时参考了过时的代码示例
- 缺少 IDE 自动补全导致手写函数名错误
