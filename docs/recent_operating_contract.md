# 近期经营数据契约

本模块补充年度质量核验：年度质量回答过去三年是否合格，近期经营核验回答最新已披露报告是否出现经营走弱。规则分、经营状态和止跌状态均不是收益概率。

## 来源和口径

`src/recent_operating.py` 使用新浪 `CompanyFinanceService.getFinanceReport2022` 的 `source=gjzb`，与 AkShare `stock_financial_abstract` 同源。直接保留原始 `publish_date`，避免 AkShare 宽表转换丢弃公告日。

来源代码核对：[AkShare stock_finance_sina.py](https://raw.githubusercontent.com/akfamily/akshare/master/akshare/stock_fundamental/stock_finance_sina.py)。字段结构另用 `sh600004` 的公开接口响应核实；这只是数据契约核对，不是个股推荐或效果验证。

只读取 `rType=合并期末`、`rCurrency=CNY`、`item_group_no=1` 的以下字段：

| 原始代码 | 含义 | 单位 |
|---|---|---|
| BIZTOTINCO | 营业总收入 | 元 |
| NETPROFIT | 合并净利润 | 元 |
| NPCUT | 扣非净利润（按源口径，不与合并净利润相除） | 元 |
| MANANETR | 经营现金流量净额 | 元 |
| SGPMARGIN | 毛利率 | 百分点 |
| SNPMARGINCONMS | 销售净利率 | 百分点 |

同名字段在其他分组重复出现时不重复读取；常用指标内部代码重复时视为歧义缺失。不会用归母净利润替代合并净利润，也不会把空值或非有限数填零。原始摘要另保留ROE及可辨识的归母净利润，供年度质量和周期正常化证据使用；它们不替代上述六项核心经营指标。

每次请求最多12个报告期，超时15秒；不在此模块重试。只用于当前荐股，不保证任意历史决策日都有对应报告。接口故障、结构变更或数据不足返回 `missing`，不能当成经营健康。

## 时效和比较基准

- 只接受合法季度末报告，且 `报告日 ≤ 公告日 ≤ 决策日`。
- 无真实公告日的记录不能成为已核验近期经营证据。
- 按报告日选择最新已披露报告；最新报告不完整时不能拿更老的完整报告顶替。
- 1–4月至少需要上一年三季报，5–8月至少当年一季报，9–10月至少半年报，11–12月至少三季报；提前披露的更新报告可立即使用。
- 同比比较必须是上一年同月同日的报告，避免跨季度现金流季节性及累计口径不一致。
- 利润、收入同比只在去年同期基数大于零时计算；负基数修复被标为观察，不伪造高速增长。现金流负基数使用金额变化，不计算普通百分比增幅。
- 这不是历史财报版本库，无法排除后来重述数据对历史口径的影响。

## 四种结果

| 状态 | 条件 | 推荐含义 |
|---|---|---|
| verified | 核心证据完整，且未触发以下条件；收入/净利/扣非单项同比下降不超过3%可通过单项检查；现金流下降不超过3%且当前累计现金流/合并净利≥0.8可通过现金流下降检查 | 近期经营这一维通过，其余荐股闸门仍须通过 |
| weak | 单项同比下降超过3%但未触发严重利润收缩；利润率明显收缩；现金流为负，或下降不满足容忍与现金转换要求；去年收入/利润基数非正 | 观察，不直接成为正式推荐 |
| failed | 当前收入/合并净利润/扣非利润非正；净利或扣非同比低于-10%；收入、合并净利润与经营现金流三项同步下降（容忍范围内仍否决） | 否决 |
| missing | 披露/报告期/同比基准/任一核心维度不足 | 待核验 |

毛利率下降超过3个百分点、净利率下降超过2个百分点视为明显收缩；函数参数可调整。净利/扣非同比恰好-10%属于观察，低于-10%才是严重收缩。`RECENT_OPERATING_YOY_TOLERANCE=3`、`RECENT_OPERATING_CASHFLOW_TOLERANCE=3` 与 `RECENT_OPERATING_CASH_CONVERSION_MIN=0.8` 控制容忍检查；现金流负值仍观察，三项同降仍failed。已知硬伤优先于缺失状态：不会因另一字段缺失而掩盖已经确认的亏损。

单季（`single_quarter`）金额由本期累计减前一季度累计推导，Q1直接用累计；TTM金额由上年全年+当年累计−上年同期推导。仅对金额流量运算，不对ROE或利润率做累计差分；所有操作数须通过公告日门控，重复或缺失操作数返回None，非正同比基数不伪造增长率。单季/TTM属于辅助证据，不填补核心缺失、不直接改变近期经营状态；归母TTM可供周期正常化估值独立使用。

年度质量模块优先真实公告日，摘要fallback缺公告日时才假定次年5月1日，并显式记录 `availability_assumed` 与公告日假定标签。**本近期经营模块及独立财务risk不采用该假定**：无真实公告日仍missing。金融企业由调用方保留专项pending；新经营指标在结果对象存在，也不代表MySQL固定白名单已将全部新字段保存。

这些是可解释的保守规则，不是统计校准后的最优参数。季度现金流下降可能来自合理经营投入，观察状态需要结合人工研究理解，不代表企业一定变差。应收账款、存货绝对增长及ROIC尚未纳入本模块，不声称已完整覆盖营运资金风险或全部行业特征；金融企业应由调用方保留专项核验分支。

## 验证

`python -B -m unittest discover -s tests -p test_recent_operating.py -v`

覆盖真实字段代码映射、公告日、同季度比较、净利阈值、利润率百分点、负基数、非有限数、重复字段、缺失不放行、已知硬伤优先和请求超时降级。全部使用合成数据与mock，不发荐股通知、不落库。
