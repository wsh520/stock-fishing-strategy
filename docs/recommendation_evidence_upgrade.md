# 本次荐股证据升级与边界

本说明记录当前荐股默认，具体资格见[荐股调整说明](quality_value_recommendations.md)，近期经营字段见[数据契约](recent_operating_contract.md)，突破信号见[突破设计](volume_breakout_strategy.md)。本次不修改交易/回测/追踪算法，不以离线规则回归声称实盘运行或业绩改善。

| 项目 | 当前默认 | 不能据此声称 |
|---|---|---|

| 低位证据 | 250日收盘中秩分位≤40%，近60日收盘底部年龄5～40日，距底上限按5ATR限制10%～20% | 250日孤立盘中低影线就是当前有效底部；固定15%仍默认 |
| 经营趋势 | 单项同比容忍3%，现金流容忍3%且现金转换≥0.8；三项同降仍failed；单季/TTM辅助 | 单季/TTM填补核心缺失或足以证明经营健康 |

| 持久化 | formal才落库；现有MySQL固定列白名单未完整保存全部新增证据 | 信号对象新增字段会自动全部存数据库 |

行业专属绝对 PE 上限通过 `INDUSTRY_PE_ABSOLUTE_CAPS` 设置，支持完整行业名称或编码（如 `{"C31": 25.0}`）；完整名称优先。关闭行业相对分位不会关闭这项上限，分类缺失时保持待核验。

周期估值终审会重新计算归母 TTM，并检查计算所需的当前累计值、上一年度值、去年同期值各自的公告日期。只有派生指标、缺少原始项的旧经营证据可以用于原有核心趋势核验，但不足以通过周期正常化估值；派生值与复算结果不一致时保持待核验。
