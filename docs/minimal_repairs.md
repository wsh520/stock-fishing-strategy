# 荐股逻辑最小修复说明

本次修复保持两策略定位和主要技术阈值，处理核验、评分、成交模拟及评价口径的一致性。

## 荐股

- 优质低估低位路径执行已有近20日日均成交额下限 `MIN_AMOUNT=30000000`。
- 行业估值准入与评分同口径：每项有分位时按 `100*(1-percentile)`，否则按原绝对估值评分，PE/PB均分。行业快照排除与指数基准日不同的行情。
- `FORWARD_MISSING_AS_PENDING=True`：近期利润同比缺失、季度无效、过旧或在决策日之后，进入pending。1–4月可使用上一年三季报或已披露年报；5–8月至少当年Q1，9–10月至少Q2，11–12月至少Q3。标签显示实际季度；这是已披露业绩核验，不是盈利预测。显式设False可恢复缺失放行。
- 突破日线通过仅产生pending候选；终审检查市场日期、财务核心有限值、补齐后的否决项、启用周线的数据充分性/新鲜度/条件及行业名额，通过才设formal。缺失写入pending_out，不占正式名额。两个周线开关独立，指数急跌熔断也作用于突破入口。
- 飞书入口只展示明确formal，缺tier、pending、fallback都不会成为推荐；落库继续只接formal。

## 成交模拟

- 优质低估低位策略次日开盘入场，入场日只盯市，禁止当日卖出（包括期末和到期退出）。跳空穿过止损/止盈按开盘成交；日内同时触及仍按配置的保守顺序。
- 停牌、无效行情、一字线采用保守成交规则，无法退出的持仓保留OPEN，不伪造平仓。
- 默认佣金单边0.03%、卖出印花税0.05%、单边滑点10bps；支持 `--fee-rate`、`--stamp-duty`、`--slippage-bps`，可置零。费用为比例模型，不含最低佣金和整手限制。
- 突破回测先使用昨日现金和持仓处理开盘买入，再处理旧仓当天退出；同日退出现金不用于当天开盘入场。
- 这些修复没有补齐历史财务数据库。OHLCV缺财务不能伪装成formal，零交易仍不能证明策略有效。

## 追踪与归因

- 推荐后第5/10/15/20个市场交易日分别观测，使用指数日期定位；允许60自然日内补跑。目标日无有效报价/停牌不前填，也不替换为最新价。
- 推荐ID+行情日期与推荐ID+固定期限双重幂等。旧数据保留原日期、价格和周号；未知期限不猜测，不混入新口径归因。
- 数据库自动迁移新增 holding_trade_days、legacy_duplicate、unique_close_date，历史同日重复仅标记；旧周号唯一索引改为普通索引，新增日期/期限唯一索引。迁移使用数据库锁串行化。
- 总体归因使用20交易日，策略分开按5/10/15/20交易日统计。统计是推荐收盘到目标收盘的信号表现，不等于实际成交收益。

## 验证及边界

离线测试覆盖流动性边界、估值评分、成长报告期、突破核验与通知过滤、T+1/跳空/无法退出/成本、突破现金时序、固定期追踪与迁移幂等。未调用真实通知、未连接生产数据库或执行实盘筛选；真实MySQL DDL尚未执行验证。交易日定位依赖指数历史日期完整，缺推荐日覆盖时跳过。

推荐数量可能减少：数据缺失现在明确进入pending。需要先补齐财务和历史数据再评价收益，不应通过放宽核验来凑推荐数量。
