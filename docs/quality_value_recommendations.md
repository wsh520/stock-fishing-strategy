# 优质低估低位与突破荐股规则

## 本次调整的原则

先判断资格，再划分正式推荐与观察候选，最后在同层内排序。年度质量、近期经营、估值和止跌分别提供证据，不能用一个维度的高分抵消另一个维度的硬伤。

默认 `run.py` 使用 `quality_value`；`run_breakout.py` 使用独立 `technical` 突破策略。两个入口保持不同选股目的，共用近期经营核验。规则分不是成功概率。本次不修改回测、交易与追踪模块。

## 年度质量、近期经营与估值

非金融企业的年度质量要求：连续3个可用完整年度，ROE中位数≥10%、每年ROE≥5%、扣非利润每年为正；默认每年合并净利润和经营现金流也为正，三年累计经营现金流/累计合并净利润≥0.8。缺失年度不能拿更旧年度顶替；季度ROE年化不能代替年度质量。

新增 `REQUIRE_RECENT_OPERATING=True`，使用最新已公告报告的收入、合并净利、扣非、经营现金流、毛利率、净利率，与去年同一报告期比较：

| 经营结果 | 默认处理 |
|---|---|
| 证据完整且未触发走弱条件 | 近期经营维度通过，其余闸门仍须通过 |
| 轻度收入/利润下降、利润率明显收缩、现金流负值或下降、去年利润基数非正 | `pending`，明确标为经营走弱或观察 |
| 当前收入/净利/扣非非正；净利或扣非同比<-10%；收入、净利与现金流同降 | `FAIL_RECENT_FUNDAMENTAL`，直接否决 |
| 关键指标、真实公告日、去年同期基准缺失，或报告过旧 | `pending`，不得当成已核验 |

毛利率收缩超过3个百分点、净利率收缩超过2个百分点进入观察；分别由 `RECENT_OPERATING_GROSS_MARGIN_DROP_MAX` / `RECENT_OPERATING_NET_MARGIN_DROP_MAX` 控制；严重利润同比阈值为 `RECENT_OPERATING_PROFIT_YOY_MIN=-10`。这些是可配置的保守规则，并非已验证的最优阈值。

同一次新浪财务摘要请求保留真实公告日，必须满足报告日≤公告日≤决策日；证据还校验股票代码、决策日与必需指标。缓存按股票、决策日及阈值隔离。取数在行情预筛后进行，突破策略在终审阶段获取。接口异常降为待核验，不以默认值补齐。来源、字段、同周期和负基数处理见 [近期经营数据契约](recent_operating_contract.md)。

默认新多维核验替代旧单项前瞻净利闸门，避免两个源的不同报告期互相冲突。只有显式关闭 `REQUIRE_RECENT_OPERATING` 后，质量策略的 `REQUIRE_FORWARD_CONFIRMATION` 才继续使用旧 Baostock 净利同比：低于-10%否决，[-10%,0%)观察，缺失默认待核验。该兼容分支的报告期验证不等于真实公告日验证。

金融企业继续待专项核验，不强套普通企业现金流和利润率规则。既有负债率、商誉与年度质量硬伤仍有独立否决效力。

估值保持行业相对PE优先：行业可比样本≥5时PE分位≤60%；不足时回退 `0<PE≤25` 并明示口径。PB默认是异常识别与提示，不参与估值评分；PB≤0仍拒绝，缺PB不单独降级。显式开启 `QV_VALUATION_DUAL_GUARD` 才恢复PB硬闸门。金融专项之外，尚未新增周期行业盈利正常化或ROIC模型。

## 价格位置和止跌分层

价格低位仍指最近250根有效日线收盘价百分位≤40%，不是每股价格低。行情时效、成交额、停牌缺口、合法OHLC和ATR风控继续独立生效。

`QV_STABILIZATION_GATE=True` 对全部市场环境生效。判据口径由 `QV_STABILIZATION_MODE` 选择，
默认 `strict` 为原口径：

| 等级 | 证据（`strict`，默认） | 资格影响 |
|---|---|---|
| 强确认 | 收盘≥MA20，MA20近5日不下行，同时站上MA60 | 通过止跌维度 |
| 中确认 | MA20确认但未站上MA60；或MACD柱连续改善且近期不创新低 | 通过止跌维度 |
| 弱确认 | MACD改善，但低点仍下移或低点证据不足 | 仅观察，不能靠综合分晋级 |
| 无确认 | MA20与MACD均无足够改善证据 | `FAIL_STABILIZATION` |

“不创新低”具体为最近5日最低价≥其前20日最低价；窗口必须完整且有效。MACD默认连续3日改善。止跌等级实际影响资格，与仅用于说明的左/右侧标签不同。

### `risk_only` 口径（`QV_STABILIZATION_MODE="risk_only"`）

实测（798只本地缓存单截面）显示 `strict` 口径下 180 只估值合格候选被砍掉 145 只（80.6%），
其中 140 只**唯一**败因是「收盘在 MA20 下方」——即该闸门实际近乎等价于一条追高条件。
`risk_only` 把「否决」与「择时标签」拆开：

| 层级 | 证据 | 资格影响 |
|---|---|---|
| 强确认 | MA20确认 且 站上MA60 | 通过止跌维度 |
| 中确认 | MA20确认；或站上MA60且近期不创新低；或MACD改善且不创新低 | 通过止跌维度 |
| 弱确认 | 仅MACD改善 | 仅观察 |
| 观察（watch） | 无止跌证据，但也不属危险形态 | 默认仅观察；`QV_STABILIZATION_WATCH_PENDING=False` 可放行 |
| 否决 | **MACD深度弱势且仍在恶化** | `FAIL_STABILIZATION` |

两点必须注意：

- 否决判据**复用 `macd_not_deeply_weak`**，与 KDJ/MACD 闸门、突破策略层 3.8 是同一实现、
  同一阈值，不存在第二套「深度弱势」定义（避免两处口径各自漂移）。
- 「站上MA20」在本口径下只产生标签，不产生否决。`QV_STABILIZATION_MODE="disabled"`
  可整体关闭闸门，用于 A/B 分离「标签」与「否决」的各自贡献。

## 价格位置的连续利用

横盘排序加分须先满足结构：最近20日振幅≤12%，且不超过前20日振幅；最近低点不低于前窗口低点；收盘标准差/均值≤4%。满足后才按距250日低点的交易日数插值：30日起算，120日到+5分。缺数据、低点持续下移或振幅扩大不给分；`CONSOLIDATION_BONUS=0` 可关闭。低点年龄本身不再证明筑底，也不被解释为成功概率。

`LOW_POSITION_MAX` 把 250 日位置二值化在 [0, 40%] 内，闸门内剩余的连续区分度被丢弃。
而实测 Spearman 秩相关（n=180）中，250日分位 ρ=−0.35，是全部因子里区分度最强的
（技术分 −0.08~−0.13、PE分位 ≈−0.03）。`QV_POSITION_RANK_WEIGHT` 把闸门内的连续位置
引回排序：`得分 = 权重 × (1 − position / LOW_POSITION_MAX)`，position=0 拿满分、
恰好压线拿 0 分。默认 `0.0`（关闭）；它只影响先后顺序，不改变任何准入判定。

## 评分、资格与排序

默认技术规则分分为三个证据组：趋势40、动能30、量价30。MA5/EMA趋势转折合并；RSI反弹、RSI多周期排列、MACD金叉及KDJ改善在动能组内取最高，不相加；多周期共振不再另奖一遍。量价质量按原评分归一化到30。分组解决重复计分，不表示三个组在统计上独立。

`DAILY_SCORING_MODE="legacy"` 可使用原趋势40+RSI25+量价25+共振10公式。显式改变旧趋势、RSI、量价或共振权重时自动进入兼容公式，使现有自定义配置继续生效。默认分组的动能满分可用 `W_DAILY_MOMENTUM_GROUP` 调整。旧技术抄底路径把陡峭MA20下降且没有底背离作为独立资格失败，避免重新分组后靠动能和量价凑够60分。

质量策略的综合分保持 `score=0.45×质量+0.30×估值+0.25×技术`。估值两种准入口径在上限处均为40分。先确定是否有缺项、经营走弱、弱止跌或技术分不足，再对正式候选执行 `MIN_QV_SCORE=50`。技术分<45进入观察；已核验质量分低于 `MIN_QUALITY_SCORE=50` 仍是硬伤。

改权重前必须先看 `describe_qv_floor`（运行时可读，`qv_floor_equivalence` 的输出）。两个硬约束：

- **三项权重之和必须保持 1.0**。只把 `TECHNICAL_SCORE_WEIGHT` 从 0.25 降到 0.10 而不把差额
  还给质量/估值，会让综合分上限从 59.5 掉到 44.5（低于 `MIN_QV_SCORE=50`），
  结果是「三道硬闸门全部压线合格」的候选被 100% 淘汰——那是在降分数线，不是在换权重。
- **抬 `MIN_QUALITY_SCORE` 会连带放松技术面**。门槛从 50 抬到 60 后，质量基线抬高，
  「过线所需技术分」从 ≥62 降到 ≥44。若目标是同时收紧质量与技术，
  两项必须成对调整（如 `QUALITY=0.55 / VALUATION=0.35 / TECHNICAL=0.10` 配合门槛 60）。

`rank_score=score+相对沪深300强度微调（最多±3）+经结构确认的横盘加分（最多5）+低位分位权重（默认0）`，仅改变通过者先后。正式候选按rank_score、质量分、估值分降序，再按代码升序；排序不能挽救未通过资格的股票。行业分散、市场数量收缩和急跌熔断继续生效。

## 突破策略终审与展示

突破保持独立的形态、量能、趋势、ATR及周线条件，并增加同一近期经营底线。初筛信号仍为pending；完成财务补齐、近期经营与周线终审后才可成为formal。终审重新验证经营状态：恶化拒绝、走弱或缺失留观察；金融企业进入专项待核验。该路径不要求质量策略的连续三年年度门槛，说明中明确写作“技术突破+基本面防雷+近期经营核验”。

质量推荐展示质量/估值/技术规则分、排序分、经营指标同比与止跌等级。`pending` 只进入观察日志，不进入正式飞书名单与推荐落库。已知走弱与缺数据使用不同原因标签。
