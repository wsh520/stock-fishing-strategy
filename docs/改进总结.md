# 长期优质低估低位策略 - 改进总结

## 项目背景

原"优质低估低位"策略存在**定位矛盾**：
- 名为"低位抄底"，实际要求"站上MA20"（80%候选被此淘汰）
- 持有期仅10-20天，不足以让价值回归
- 3年质量要求无法穿越完整经济周期
- 缺乏对"长期投资资质"的量化评估

## 改进成果

已创建**长期优质低估低位策略（quality_longterm）**，作为原策略的增强版本，专门服务于3-12个月持有周期的价值投资者。

## 六大核心创新

### 1. 穿越周期的质量检验（5年 vs 3年）
```python
QUALITY_YEARS: int = 5
QUALITY_MEDIAN_ROE_MIN: float = 12.0  # vs 原10%
QUALITY_MIN_ROE: float = 8.0  # vs 原5%
```
**理由**：5年覆盖完整经济周期，过滤掉"周期性繁荣"伪装的优质股。

### 2. ROE稳定性量化（新增）
```python
REQUIRE_ROE_STABILITY: bool = True
MAX_ROE_CV: float = 0.5  # 变异系数上限
```
**评分公式**：
```python
stability_score = 100 * (1 - CV/0.5)
# CV=0（完全稳定） → 100分
# CV=0.5（临界值） → 0分
```

### 3. 盈利持续性检查（新增）
```python
REQUIRE_EARNINGS_CONSISTENCY: bool = True
MIN_POSITIVE_GROWTH_YEARS: int = 3  # 5年中至少3年正增长
```
**避免**：爆发式增长+断崖式下跌的不稳定公司。

### 4. 止跌判定从"追涨"改为"避险"
```python
QV_STABILIZATION_MODE: str = "risk_only"  # 强制改为risk_only

# 原策略：无止跌证据→淘汰（80%被拦）
# 长期版：只拒绝"MACD深度弱势且连续恶化"（加速下跌）
if MACD柱/收盘 <= -0.8% and 连续3日递减:
    return None, "FAIL_STABILIZATION"
else:
    # 分层为strong/medium/weak/watch，但不淘汰
    stabilization_level = ...
```

### 5. 底部窗口大幅放宽
```python
QV_RECENT_LOW_MIN_AGE: int = 3   # 5→3天（允许V型反转）
QV_RECENT_LOW_MAX_AGE: int = 90  # 40→90天（允许长期磨底）
QV_LOW_GAIN_ATR_MULT: float = 8.0  # 5→8倍ATR
```
**允许形态**：V型反转、W型双底、箱体磨底。

### 6. 长期投资资质评分（核心创新）
```python
ENABLE_LONGTERM_QUALITY_SCORE: bool = True
MIN_LONGTERM_QUALITY_SCORE: float = 60.0
```

**五大维度评分（0-100分）**：
| 维度 | 权重 | 满分条件 |
|------|------|---------|
| ROE稳定性 | 25% | CV=0 |
| 现金流质量 | 25% | 5年现金流/净利润≥1.2 |
| 盈利持续性 | 20% | 5/5年正增长 |
| 增长质量 | 15% | ROE年增0-2pp（温和增长） |
| 估值安全边际 | 15% | PE行业分位=0% |

**实际案例**：
```python
# 某优质公司
年份:   2020  2021  2022  2023  2024
ROE:    11%   13%   12%   14%   13%  → CV=0.10 → 稳定性80分
现金流/利润: 1.12 → 现金流质量80分
正增长: 5/5年 → 盈利持续性100分
ROE增速: 0.5pp/年 → 增长质量100分
PE分位: 30% → 估值边际60分

综合得分 = 0.25×80 + 0.25×80 + 0.20×100 + 0.15×100 + 0.15×60 = 84分
→ 通过60分门槛 ✓
```

## 完整筛选流程

```
输入：股票代码 + 5年财务数据 + 日线数据
  ↓
【继承原策略基础闸门】
  ├─ 流动性（日均成交额≥5000万）
  ├─ 250日低位（分位≤40%）
  ├─ 估值（行业分位≤50% 或 PE≤25）
  ├─ 近期经营与财务风险
  ↓
【长期投资专项增强】
  ├─ 5年质量（ROE中位≥12%、最低≥8%）
  ├─ ROE稳定性（CV≤0.5）
  ├─ 5年现金流质量（累计≥1.0）
  ├─ 盈利持续性（5年中≥3年正增长）
  ├─ 长期投资资质评分（≥60分）
  ├─ 相对强度（近60日跑输<-15%拒绝）
  ↓
【底部与止跌】
  ├─ 近期底部（3-90天，距底≤35%）
  ├─ 止跌判定（risk_only，只拒绝加速下跌）
  ├─ 技术状态（≥30分即可）
  ↓
【排序与输出】
  ├─ 综合评分：55%质量 + 35%估值 + 10%技术
  ├─ 行业分散（每行业≤2只）
  ├─ 数量截取（牛3/中2/熊1）
  ↓
输出：长期优质低估低位推荐
```

## 设计哲学转变

| 维度 | 原策略 | 长期版 |
|------|--------|--------|
| **核心目标** | 抓短期反弹 | 长期价值投资 |
| **入场时机** | 刚开始止跌（追求精准） | 已充分磨底（追求安全） |

| **退出依据** | 止盈30%或持有20天 | 止盈50%或持有90天 |
| **定位** | 中短期价值投机 | 传统价值投资 |

## 风险提示

1. **数据依赖**：需要5年连续财务数据，新股/借壳股无法使用
2. **推荐频率降低**：可能连续多日无推荐（严格筛选的代价）
3. **不适合短线**：30-90天持有期，不适合快进快出
4. **机会成本**：持有期长意味着资金周转慢
5. **需实测验证**：策略优化基于逻辑推理，实际效果需回测验证
