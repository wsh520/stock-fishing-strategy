# 离线技术消融与底部影子诊断

本工具只读取本地行情 CSV，调用指标纯函数；不请求行情、不读取或写入数据库、不推送、不修改生产配置。输出不参与选股。生产底部仍使用原来的近期最低收盘锚点。

## 运行

```powershell
.\.venv\Scripts\python.exe diag_technical_bottom_ablation.py --input backtest_cache/daily --as-of 2025-06-30 --limit 10 --output report.json
```

`--input` 接受单个 CSV 或含 CSV 的目录；不存在的路径或没有 CSV 的目录会明确报错并以退出码2结束。`--as-of` 可以重复，日期必须在各股票缓存中存在；`--limit 0` 使用全部文件。省略 `--output` 时 JSON 打印到标准输出。输出目录须已存在。

输入列：`date, open, high, low, close, volume, amount`。工具重算 `pct_chg` 和指标；不会使用缓存中可能由未来数据计算的指标列。纯 OHLC 缺少量价评分所需的成交量/成交额时，会明确跳过并报告缺列，不填造数据。所有输入应使用一致复权口径；缓存修订和幸存者偏差无法由本工具消除。

## 比较口径与输出

三个布尔组：`current_stab_and_tech40`（现行 strict strong/medium 且技术分 >=40）、`stabilization_only`、`technical_only`。技术分采用当前配置的 `qv_daily_score`，现行 weak 仅为 pending，不能算止跌正式准入。脚本不修改配置对象。各组共用相同输入观察总体；**没有重建财务、估值、流动性等完整生产候选池，因此不能把组计数当成生产推荐数量**。

每个 `observations` 元素包含：股票、决策日、技术分、止跌层、三组标记、`production_bottom`、`shadow_bottoms`，以及未来第5/10/20根有效成交bar的收盘相对决策日收盘变化。决策日 `volume` 或 `amount` 为零时按 `as_of_no_trading` 跳过；历史先移除零成交停牌占位，再重算 `pct_chg` 与指标。前瞻标签另行从 `as_of` 之后按 `volume>0` 且 `amount>0` 的有限值bar计数，不以原CSV行号或过滤后的历史长度定位。指标和底部只用 `as_of` 及之前的数据；未来数据仅用于前瞻标签，有效bar不足则为 null。这些标签不是成交回测，不含费用、交易限制、基准调整。

`groups` 给出组内样本数、股票数、日期数和每个期限的完整/缺失标签数、均值、中位数。默认每组每期限至少30个完整标签且至少5个不同决策日；不足输出 `insufficient_no_return_conclusion`。达到门槛也仅输出 `descriptive_only`，股票与重叠窗口并非独立样本，不能由此断言收益改善。`skipped` 说明无法计算的文件/日期原因。

## 纯函数接口

- `assess_low_structure(out, as_of, recent_window=60, min_age=5, max_age=40, atr_multiple=5.)`：原签名和原字段语义不变，只增加 `failure_reasons`。可同时包含 `too_new` / `too_old` 与 `overextended`；即使年龄不合格也独立诊断超涨。缺ATR时保留已知年龄原因，但不猜测超涨；数据缺失仍由 `status/reason/missing_detail` 表示。
- `assess_shadow_bottoms(out, as_of, window=120, left_bars=3, right_bars=3, min_separation=5, retest_tolerance=.03, min_rebound=.04)`：只需 `date/close`，不变更输入。返回 `shadow_only=True`、`status/reason`、按时间排列的 `local_bottoms` 和 `double_bottoms`，没有替代生产锚点字段。

局部底：低于左侧3根收盘；右侧3根收盘均严格更高才确认。尚未观察足够右侧bar为 `unconfirmed`；确认窗口失败或后续收盘跌破为 `invalidated`。输出锚点/日期、交易bar年龄、相对当前收盘涨幅、确认日和失效日；失效后不会因重新反弹自动恢复。

二次底：从已确认第一底开始，只配对首个间隔合格、距第一底±3%内的可比回踩；中间须有至少4%的收盘反弹。第二底完成右侧确认且随后收盘突破中间最高收盘颈线才为 `confirmed`；跌破两底较低支撑为 `invalidated`。输出两底价格/日期、支撑、颈线、确认/失效日。`gain_pct` 始终相对第一底，`support_gain_pct` 相对两底较低价，不采用更高第二底降低涨幅。局部底全部列出，没有按最小涨幅择优挑底。
